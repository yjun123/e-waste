# Xereox ET1020

[English](README.md) · 简体中文

从QQ群友手上淘到的平板，原来是施乐打印机的控制面板 [1](https://github.com/retro98boy/rockchip-devices/tree/main/devices/xerox-et1020#%E7%A1%AC%E4%BB%B6)。 没有电池🔋，需要插电使用（Type-C)。

![](images/outside/Front.jpg)
