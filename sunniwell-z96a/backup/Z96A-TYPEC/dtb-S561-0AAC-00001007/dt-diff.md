# 朝歌 Z96A 至 Z96H (双 Type-C 版) 设备树适配文档

## 一、 核心硬件架构演进

* **主板形态**：从“DC供电 + 单 Type-C”升级为现代化的“双 Type-C”架构。
* **电源管理**：核心 PMIC 由 RK817 变更为 **RK809**，并引入独立的南芯 **SC8886** 负责大功率 PD 快充。


* **网络模块**：无线网卡由 RTL8821CS 升级为支持多天线的 **RTL8822CS**。



## 二、 电源与电池系统适配 (重点)

由于采用 8.4V 双节串联锂电，新旧主板均采用“电阻分压 + ADC 采集”的策略计算电量。

* **充电接管**：在 `i2c0` 总线节点下新增 `sc8886@6b` 智能快充节点，并移除旧版已废弃的 `fusb302` 芯片。


* **电量采集逻辑**：必须继续**沿用老版本内核**中对 `rk817_battery.c` 驱动的“手搓”修改补丁，以保留写死的电阻分压换算比例。
* **设备树修正**：将主控 PMIC 变更为 `rk809`，并将 `battery` 节点的 ADC 采集通道修正为通道 5 (`io-channels = <&saradc 5>`)。



## 三、 显示与通信模块适配

屏幕面板规格与背光链路发生了物理变更，未适配将导致色彩断层或黑屏。

* **显示面板**：将 `edp_panel` 节点的总线格式修改为 `0x1009`，色深配置为 `bpc = <6>` (6-bit 屏幕)。


* **背光控制**：背光 PWM 通道由 `pwm10` 更改为 `pwm9`，同时新增背光硬件使能引脚，配置为 `enable-gpios = <&gpio2 RK_PD5 GPIO_ACTIVE_HIGH>`。


* **无线网络**：将 `wlan-platdata` 中的芯片型号声明更改为 `rtl8822cs`，并将蓝牙模块的唤醒引脚 `BT,wake_gpio` 修正为 `RK_PB0`。



## 四、 外设引脚修正与扩展

* **内置输入设备**：键盘与触摸板的供电不再混合，主板为其分配了独立的 `vcc5v0-usb-keyboard` 供电节点，需受 `gpio2 RK_PD7` 引脚控制。


* **麦克风阵列**：新主板在 `i2c3` 总线上新增了两颗独立的 **ES7202** PDM 模数转换芯片，用于支持多麦克风拾音。
